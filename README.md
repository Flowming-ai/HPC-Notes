# HPC Notes

Review notes for COSC/ECCE 738 High-Performance Computing (Khalifa University, Fall 2026).

Open `HPC_notes.html` in a browser for the full review notes, or `HPC_exam_notes.html` for the short version for the last days before the exam (core concepts, must-know formulas and worked examples). Both work offline: the formula and code-highlighting libraries are in `assets/` and the figures in `img/`.

In the full notes:

- The notes contain only what the lecture slides and Assignment 1 contain.
- Every chapter starts with an **Exam map**: what can be asked and the key formula.
- Every section is one exam item with a priority: ★★★ core, ★★ likely, ★ recognise the term.
- Each section has the must-know points, formula cards with every symbol explained, one worked example, the usual traps and practice questions with answers.

Both versions are in English with a Chinese translation under each block; the language button in the sidebar switches between bilingual, English only and Chinese only.
