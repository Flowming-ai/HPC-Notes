# HPC Notes

Review notes for COSC/ECCE 738 High-Performance Computing (Khalifa University, Fall 2026).

Open `HPC_notes.html` in a browser. It works offline: the formula and code-highlighting libraries are in `assets/` and the figures in `img/`.

- Every chapter starts with an **Exam map**: what can be asked and the key formula.
- Every section is one exam item with a priority: ★★★ core, ★★ likely, ★ recognise the term.
- Each section has the must-know points, formula cards with every symbol explained, one worked example, the usual traps and practice questions with answers.
- The text is in English with a Chinese translation under each block; the button in the sidebar hides the Chinese.
